## 🎯 Project Overview

The VWAP algorithm is a Python project built around historical market data processing and technical indicator analysis.

It reads candle data from JSON files, processes market prices and trading volumes, and performs sequential calculations using a Wilder-style smoothing methodology.

The implementation includes calculations associated with directional movement and trend-strength analysis, including:

* True Range (TR)
* Directional Movement (+DM and -DM)
* Positive and Negative Directional Indicators (+DI and -DI)
* Directional Index (DX)
* Average Directional Index (ADX)

The implementation also contains candle-processing logic intended to support the evaluation of potential market conditions.

> **Note:** Although this project is named a VWAP algorithm, the calculations described above are associated with the Directional Movement Index (DMI) and ADX family of indicators. The current implementation should be verified before describing its output as a conventional Volume Weighted Average Price (VWAP).

## 📊 Technical Calculations

### 1. True Range (TR)

True Range measures the range of price movement while accounting for the previous candle's closing price.

A conventional calculation is:

$$
TR = \max
\begin{cases}
H-L\\
|H-C_{prev}|\\
|L-C_{prev}|
\end{cases}
$$

Where:

* \(H\) = Current candle high
* \(L\) = Current candle low
* \(C_{prev}\) = Previous candle close

### 2. Directional Movement

Directional movement compares changes in consecutive candle highs and lows.

$$
+DM = H_t-H_{t-1}
$$

$$
-DM = L_{t-1}-L_t
$$

These values are conventionally filtered so that only the dominant positive or negative movement is retained, with non-positive movements set to zero.

### 3. Directional Indicators

The positive and negative directional indicators compare smoothed directional movement against smoothed True Range.

$$
+DI = 100 \times \frac{Smoothed(+DM)}{Smoothed(TR)}
$$

$$
-DI = 100 \times \frac{Smoothed(-DM)}{Smoothed(TR)}
$$

These indicators help quantify upward and downward directional movement.

### 4. Directional Index (DX)

The Directional Index measures the relative difference between the positive and negative directional indicators.

$$
DX = 100 \times
\frac{|+DI-(-DI)|}{+DI+(-DI)}
$$

The denominator must be handled safely when both directional indicators are zero.

### 5. Average Directional Index (ADX)

ADX applies smoothing to DX to measure trend strength.

A conventional Wilder-style recursive update is:

$$
ADX_t =
\frac{(n-1)ADX_{t-1}+DX_t}{n}
$$

Where:

* \(n\) = Smoothing period
* \(ADX_{t-1}\) = Previous ADX value
* \(DX_t\) = Current DX value

The exact initialization and update formulas should be checked against the actual implementation before treating its output as a standard ADX series.

## ⚠️ Important Notes

* **Indicator naming:** The project name is VWAP, but the calculations described in the current implementation include True Range, directional movement, DI, DX, and ADX-related logic.
* **Conventional VWAP:** Standard VWAP is generally calculated using price multiplied by volume, accumulated over a session and divided by cumulative volume. Do not assume the current output is conventional VWAP without verifying the calculation.
* **Data fields:** Check whether the source uses `CLOSE`, `CLOSING_PRICE`, or another closing-price field. JSON keys must match the code.
* **Date filtering:** Confirm that the configured date matches the available dataset.
* **Initialization:** Recursive smoothing requires appropriate initial values and sufficient historical candles.
* **Calculation validation:** Compare indicator outputs against a trusted reference implementation before relying on them.
* **Trading signals:** The presence of technical indicators does not establish that a trading setup is profitable or reliable.
